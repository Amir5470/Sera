Security-driven changes — Partial State routing logic

- New behavior added to the Feed screen routing guard to handle "partial state" situations discovered by the Security Auditor:
  - If a user has `onboardingComplete: true` but their `userIndex/{uid}` document is missing `schoolId`, the app will now redirect the user to `/ (app) /settings/edit-school` instead of restarting onboarding.
  - Previously, users in this inconsistent state could be pushed back into onboarding step3 repeatedly, causing confusing loops. The new redirect sends them to Settings where they can explicitly set their school and resolve the inconsistency.
  - Implementation note: The guard is implemented in app/(app)/feed/index.tsx at the top-level effect that watches `profile` and `profileLoading`. It checks `profile.onboardingComplete && !profile.schoolId` and then calls `router.replace("/(app)/settings/edit-school")` to avoid back-button loops.
